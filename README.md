# Game Pass Tracker — Dati

Questo repository contiene i dati sui giochi in arrivo, annunciati e in
uscita da Xbox Game Pass, usati dall'app **Game Pass Tracker**.

Il file `upcoming_data.json` viene aggiornato automaticamente ogni giorno
da un GitHub Action (vedi `.github/workflows/update.yml`), che analizza
le pagine pubbliche di [gg.deals](https://gg.deals) dedicate al catalogo
Game Pass.

Non serve modificare nulla a mano: l'automazione fa tutto da sola.
